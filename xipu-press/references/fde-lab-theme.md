# FDE Lab Theme（xipu-press 第二主题范式）

从《AI 领导力——当 AI 开始工作，你准备好了吗》v1.0（2026-10-27，22 页全图 PPT，王大鹏教授）逐页取样得到。色值用 PyMuPDF 对渲染位图做直方图与区域取样，不是目测。本主题用于 FDE Lab 名下的展示物：poster、分享页、展板、一页纸。**不用于管理文件与公函**（那些走 XJTLU house style）。

## Palette

| Token | Value | 取样来源 | 用途 |
|-------|-------|---------|------|
| `--bg` | `#F4F4F2` | 全页底色 | 页面底 |
| `--ink` | `#232323` | 标题、深色条、深色圆点 | 标题、keybar、num-dark |
| `--ink-soft` | `#3A3A38` | 卡片正文 | 正文 |
| `--gray-text` | `#6E6E6A` | 副标题、脚注 | 次级文字 |
| `--eyebrow` | `#8A8A86` | 页眉小标签 | eyebrow |
| `--bar-1` | `#E4E4E2` | 斜向几何条（浅） | 背景几何 |
| `--bar-2` | `#D8D8D6` | 斜向几何条（中） | 背景几何 |
| `--bar-3` | `#CCCCCC` | 斜向几何条（深） | 背景几何 |
| `--card` | `#EFEFED` | 灰底卡片 | 普通卡片、rail 底 |
| `--card-white` | `#FCFCFC` | 白底卡片 | 强调对照卡 |
| `--lime` | `#D2F857` | 封面三角、下划条、圆点、卡片描边 | 结构色与高亮填充 |
| `--lime-pale` | `#F5FBD2` | 高亮卡片底 | hl 卡片底 |
| `--olive` | `#6D8400` | 浅色底上的强调文字、图标 | 浅底强调字、图标 |

对比纪律：`--lime` 只作填充与线条，不作浅底正文（对比不足）；浅底强调字一律 `--olive`；深色条（keybar）上的强调字用 `--lime`。

## Typography

- 中文：`'PingFang SC'`；标题 weight 700–800，正文 400。
- 拉丁：`'DIN Alternate','Arial'`；eyebrow 与标签全大写、字距 `.18em`。
- 层级（A2 poster）：eyebrow 13pt；主标题 92–104pt／700；副标题 28pt／400 灰；节标题 30pt／700；正文 17pt／1.5；卡片小字 14pt；脚注 12pt。
- 层级（A4 一页纸）：约为上表一半：主标题 44pt、副标题 14pt、节标题 15pt、正文 9pt、脚注 6.5pt。
- 标题可双色：前半 `--ink`，强调段 `--olive`（参考 P12「从 Tool 到 Actor:」黑＋「AI 开始真正做事了」橄榄绿）。poster 上主标题通常两行堆叠（第一行模式名、第二行中文强调段），避免与右上三角相碰。
- 主标题下可加一条 lime 短横（宽约标题 1/6、高 4mm），也可不加；加了就全篇统一加。

## Components

**eyebrow-row**：左＝lime 短横＋全大写小标签（`STORY 01 · …` 式）；右＝lime 短横＋小注或页码（`P12 / 22`）。每页必有。

**title-block**：主标题（可双色）＋副标题灰字；可选 lime 下划条。

**geo-bars**：三至四条斜向灰条（`--bar-1/2/3`），从右上出血，只占页面上部一条带（poster 上约 top 44–160mm），仅作封面、分节页、poster 顶部背景；正文页与卡片区域不用。实现上给 `.geo` 加 `clip-path: inset(0 0 60% 0)`，把斜条裁在页面上部，避免旋转后的条端从卡片缝隙里露出来。

**tri**：lime 描边三角（播放键形），粗描边、中空；封面与分节页的主视觉符号。用内联 SVG，不用位图。

**card**：圆角 6px。三种：`.card`（`--card` 底）、`.card.white`（`--card-white` 底）、`.card.hl`（`--lime-pale` 底＋1.5px `--lime` 描边，用于"当前重点/推荐项"）。

**num-dot / num-dark**：`--lime` 圆底＋`--ink` 数字（列表、要点）；`--ink` 圆底＋白数字（循环、流程节点）。直径约正文行高的 1.6 倍。

**rail**：右侧栏面板，`--card` 底，左缘 3px `--lime` 竖条；标题 ink 粗体；用于"核心观点/关键数字"。

**keybar**：`--ink` 通栏条，白字，强调词用 `--lime`；放全篇最重要的一句话。poster 放底部，分享页放页底。

**logo-lockup**：FDE LAB 字母组合标（使用随模板提供的 `fde-lab-logo.png`，不重绘）＋`FDE LAB` 字标＋竖细分隔＋`Think.` `Build.` `Impact.` 三行堆叠。封面右下；内页页脚只放 lime 短横＋`FDE LAB` 字标。

**footer**：左＝来源与免责小字（灰）；右＝logo 或 lime 短横＋字标。

**icons**：单色线性图标，`--ink` 或 `--olive`，线宽 2，尺寸约正文 2.2 倍；不填充、不渐变。

**arrows**：流程用细灰直箭头；循环用粗灰弯箭头。

## Poster 版式（A2 竖版，默认）

- 页面 420×594mm，`@page { size: 420mm 594mm; margin: 0; }`，内边距 20mm。
- 结构自上而下：eyebrow-row → geo-bars＋tri 背景区（高约 90mm）→ title-block → 主区两栏（左 7 右 5：左放流程与卡片，右放 rail 与数字）→ keybar → footer。
- 主区栏距 12mm；卡片间距 8mm；rail 内条目用 num-dot。
- 一屏只讲一件事：poster 承载"这套模式是什么、边界在哪、怎么跑、要多少钱、要拍什么"五组信息，每组一个卡片或一个 rail 条目，不堆段落。
- 打印：CMYK 安全起见 lime 在大面积填充时改为 `#C9EF45`；小面积保持 `#D2F857`。

## 文案纪律（展示物专用）

展示物（poster、一页纸、分享页）一律用肯定句：分工写"谁承担什么"，承诺写"以验收结论为准"，判据写"验收看一条：……"。标题里不出现"非／不／未"。否决条款、红线、"不做什么"清单留在方案与细则（03 总框架、10 号运行细则容器），不上展示物——展示物的任务是让人记住这套模式做什么、怎么跑、要什么支持。

标题按听众选。面对业务侧或混合听众时，标题讲对方得到什么（例："做完一个项目，留下一支会做的队伍"）；"让对方的人自己做"这类表述只在内部方案里作为验收判据出现，不上展示物标题。

## 禁止项

无渐变、无阴影、无照片作底、无圆角超过 6px、无 lime 作浅底正文、无第四种强调色、无装饰性位图。几何灰条只出现在封面/分节/poster 顶部，正文页保持干净。
